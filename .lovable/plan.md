

# تحسين فلاتر صفحة الكتب - عرض التخصصات كفروع

## الفكرة
حالياً تظهر اللغات والتخصصات معاً دائماً. المطلوب: التخصصات تظهر فقط بعد اختيار لغة معينة، كفروع أسفل أزرار اللغات.

## التغييرات - ملف واحد: `src/pages/BooksPage.tsx`

1. **إخفاء صف التخصصات** عندما تكون اللغة "الكل" - يظهر فقط عند اختيار لغة محددة (عربية/فرنسية/إنجليزية)
2. **إضافة تأثير انتقال** عند ظهور/اختفاء صف التخصصات (animation slide-down)
3. **تمييز بصري** لصف التخصصات كفرع من اللغة المختارة (مسافة بادئة خفيفة أو خط ربط)
4. **نفس شكل الأزرار** بالضبط - نفس الألوان والحجم والتصميم الحالي

### السلوك:
- المستخدم يفتح صفحة الكتب → تظهر أزرار اللغات فقط (+ الفرز والبحث)
- يضغط على "العربية" → تظهر أسفلها أزرار التخصصات العربية (تاريخ، علوم، طب...)
- يضغط على "Français" → تتغير التخصصات للفرنسية
- يضغط على "الكل" → تختفي التخصصات
